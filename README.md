# MindEcho

**AI-Powered Mood Journal & Wellness Management System**

MindEcho is a web application that allows users to track their daily moods, journal their thoughts, and receive AI-generated insights and motivational suggestions. This system supports multiple roles (User & Admin) and integrates AI analysis through OpenRouter.ai using Python (Flask/FastAPI) backend.

## Features
- User authentication (Register, Login, Logout) with JWT
- Daily mood tracking (emoji + journal entry)
- AI-generated mood analysis and motivational tips
- Mood analytics and trends visualization (charts)
- Admin panel to monitor overall user statistics
- Multi-role system (User & Admin)

## Tech Stack
- Frontend: React.js
- Backend: Node.js + Express.js
- Database: MongoDB
- AI Service: Python (Flask/FastAPI) + OpenRouter.ai
- Authentication: JWT
